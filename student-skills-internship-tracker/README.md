Pathfinder – Student Skills & Internship Tracker

About the Project

Pathfinder is a student-focused web application designed to help students track their skill development and explore internship opportunities.

It provides a simple dashboard where students can monitor their skills, update learning progress, search for internships, save interesting opportunities, and track applications.

Features

- Student Dashboard: View an overview of skills and internship opportunities.
- Skill Tracking: Monitor skill development and update progress.
- Add New Skills: Add skills with different categories.
- Internship Search: Search internships by role, company, location, or skill.
- Category Filtering: Filter opportunities by Technology, Design, and Business.
- Save Internships: Save interesting internship opportunities.
- Application Tracking: Mark internships as applied and track application counts.
- Responsive Design: Access the dashboard on desktop and mobile devices.

Installation and Setup

Follow these steps to run the project locally.

Step 1: Install Node.js

Download and install Node.js from:

https://nodejs.org/

Step 2: Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_LINK

Step 3: Open the Project Folder

cd student-skills-internship-tracker

Step 4: Install Dependencies

npm install

Step 5: Run the Development Server

npm run dev

Step 6: Open the Application

Open the local URL displayed in your terminal, usually:

http://localhost:5173

Production Build

To create a production-ready build, run:

npm run build

The generated production files will be available in the "dist" folder.
